Privacy Policy: Claude MCP

Last updated: November 21, 2026

Who uses it. This app is a private connector used only by its owner, so the owner's own AI assistant can work with the owner's own Google accounts. It is not offered to anyone else.

What it reads. With the owner's consent, access to the owner's Gmail, Google Drive, Docs, Sheets, Slides and Calendar data, as allowed by the permissions granted at sign-in.

How the data is used. Data is used only to carry out the owner's own requests on the owner's own computers. It is not sold, shared with third parties or used for advertising.

Google API data. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be revoked at any time at myaccount.google.com/permissions.
